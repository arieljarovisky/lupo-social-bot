Probar un mensaje

Escribí lo que diría un cliente. La vista previa usa los textos que estás editando, aunque todavía no los hayas guardado.

Todavía no probaste ningún mensaje.
Si no hay palabra clave, el bot no contesta en público.

Intenciones

El bot usa la primera coincidencia. Las palabras clave son patrones; “precio” alcanza a “precios”. Podés usar expresiones simples como tall[ea].

Mensajes extra de Instagram

Solo se usan si IG_PRIVATE_REPLIES=true. En el comentario público aparece el aviso; el detalle va por privado.

Una variante por línea. El bot las alterna para no repetir siempre el mismo aviso.

En los DMs, {{store}} es el link de la tienda y {{whatsapp}} es el link de WhatsApp. Dejá un espacio antes de cada variable.

Posts con productos

En cada publicación podés escribir el mensaje general y, si querés, uno distinto para talle, precio y el resto. Si un caso queda vacío, se usa el mensaje general de ese post. Hace falta IG_PRIVATE_REPLIES=true para el privado.

ID de la publicación

Cargá las últimas publicaciones o pegá el link de un post, reel o video. El ID es el número que va en el mapeo.

Agregar mapeo

Este texto se publica debajo del comentario, solo en este post.

Estos dos valen para cualquier comentario de este post. Abajo podés cambiar solo talle, precio u otro caso. Variables: {{nombre}}, {{url}}, {{store}} y {{whatsapp}}.

Los cambios se guardan en el servidor y el bot los usa enseguida.
